# Overview

`@johannes.latzel/pattern-specific` resolves an input against a set of glob rules and merges the matching ones, with more specific rules overriding less specific ones. It is used by [llm-chat-shell](https://github.com/johanneslatzel/llm-chat-shell) permissions and [llm-chat-web](https://github.com/johanneslatzel/llm-chat-web) header rules.
